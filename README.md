# Selah · Comentários Renderizados (Português)

Renderizações em português dos comentários clássicos da Bíblia
Hebraica, produzidas pelo projeto Selah — um diretório por voz, um
arquivo EDN por comentário (`<voz>/<livro>/<capítulo>/<versículo>.edn`),
traduzidas das renderizações inglesas de Selah (que por sua vez vêm
do hebraico de domínio público).

As renderizações guardam a disciplina da casa: os Nomes divinos são
transliterados (YHWH, Elohim, Adonai…), as citações hebraicas
permanecem em hebraico — letra por letra, verificadas mecanicamente —
e a aritmética de guematria é preservada tal como o comentarista a
escreveu.

Vozes: Baal HaTurim · Chizkuni · Daat Zkenim · Ibn Ezra · Kli Yakar ·
Or HaChaim · Rabbeinu Bahya · Ramban · Rashbam · Sforno.
